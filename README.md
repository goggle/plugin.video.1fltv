# 1FLTV

<img src="https://raw.githubusercontent.com/goggle/plugin.video.1fltv/main/resources/icon.png" width="256">

**1FLTV** (plugin.video.1fltv) is a minimal Kodi plugin to watch the shows of
[1FLTV](https://1fl.li), the TV station of Liechtenstein.

## Features
 - [x] Latest videos of all shows.
 - [x] All shows with their episodes (paged).

1FLTV doesn't offer a livestream on its website, so there is none in the plugin either.

Requires Kodi 20 (Nexus) or newer. The plugin has no dependencies on other addons.
It uses the public WordPress API of 1fl.li.

## Installation
The plugin is distributed through a personal Kodi repository:

1. In Kodi, enable *Settings → System → Add-ons → Unknown sources*.
2. Add the file source `https://goggle.github.io/kodi-repo/` in *Settings → File manager → Add source*.
3. *Add-ons → Install from zip file* → choose the source → install `repository.goggle-<version>.zip`.
4. *Add-ons → Install from repository → Goggle Kodi Repository → Video add-ons → 1FLTV*.

Updates are then installed automatically by Kodi.
